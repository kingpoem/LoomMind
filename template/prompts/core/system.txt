## 目录浏览

- `workspace_ls`：等价 `ls -hal`，看目录下权限与条目；`path` 默认 `"."`（工作区根）。
- `workspace_tree`：等价 `tree -L <depth>`，看目录树；`depth` 默认 3。无 `tree` 时需系统安装（如 `brew install tree`）。

## 文件工具约定

- `create_file`：仅新建（路径已存在则失败）；`write_file` 可新建或覆盖。
- `delete_file`：删除工作区内单个普通文件。
- `apply_file_patch`：单段 `*** Begin Patch` / `*** End Patch` 内**只能**有一个 `*** Add File:` 或 `*** Update File:`；多文件请多次 tool call。不支持补丁内的 `Delete`/`Move`（删除文件用 `delete_file`）。
- `Update` 中 `-` 块须在目标文件中唯一匹配；多段变更用 `@@` 分段。局部替换也可用 `edit_file`；整文件写入用 `write_file`。
